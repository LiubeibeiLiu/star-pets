# 星星宠物 · 共享界面设计与交互规则

## 设计方向与源码边界

产品面向儿童与家庭共同使用：伙伴形象承担情感重心，记录与设置以清晰、安静、可信的操作界面承载。参考 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的儿童宠物产品检索结果，采用其“温和、可触、轻动效”的原则；未照搬检索器给出的橙色配色、营销页结构和联网字体，因为本产品已有三主题、中文字体与应用内任务流。

Android 与 iOS 的 Web 界面都从本工程 `ui/` 构建。`npm run build:web` 写入 Android 的 `assets/web/`，`npm run build:web:ios` 写入同级 iOS 工程的 `StarPets/web/`。布局和组件只能在 `ui/src/` 改一次；原生桥接和安全区由各平台处理。

## 页面与操作逻辑

底部五栏固定为习惯、回忆、小窝、伙伴、设置。`App.vue` 的 `view`、`habitMode`、`habitTab`、`memoryTab` 决定当前画面；子页隐藏底栏并通过页头返回。`nav()` 负责切页时关闭临时浮层，`back()` 按浮层、模态框、子页层级处理。新增入口必须接入这套状态转换，不能只改变文案或样式。

底栏入口使用 `navTop()`：进入目的地时从顶部开始；再次点当前底栏项也回到顶部。子页返回继续使用按视图保存的滚动位置，避免图鉴、回忆详情返回后丢失阅读位置。界面主题在进入设置页时应完整显示当前选中项；窄屏改用纵向主题选项，因此提示文案不依赖滑动方向。

空计划页显示一个明确的“挑选培养计划”入口。搜索无结果时提供清除操作。分页只有超过一页才出现；没有可翻页内容时不显示“第 1/1 页”。删除、撤销、恢复备份等操作说明影响范围，并由确认动作提交。录音期间不允许无提示离开录入层。

小朋友档案列表以整行点击切换使用者，右侧齿轮单独进入该档案编辑页；当前使用者用文字与主色标明，不使用单选按钮冒充设置入口。小窝的今日计划只列未完成项目；探索中的伙伴展示目的地风景，探索回忆通过“探索”筛选查看。

## 令牌与五主题

`ui/src/styles/tokens.css` 是色彩、尺寸和动效的事实来源。组件消费 `--ink`、`--ink-2`、`--surface`、`--fill`、`--primary`、`--primary-soft`、`--danger` 等语义变量，不在单个页面硬编码主题色。

| 层级 | 规则 |
| --- | --- |
| 页面 | 露草蓝用浅蓝灰，星雾紫用浅薰衣草，星夜黑用深蓝黑，暖陶 Milo 用暖奶油，蔚蓝用浅灰蓝；背景光晕只提供环境感，不承担文本对比 |
| 主卡片 | 实色表面、细边框、低对比阴影；浮层和导航可保留半透明模糊。避免多层卡片同时叠加玻璃模糊 |
| 内嵌控件 | 输入、分段、计划和目标卡使用比父表面低一级的填充；选中态用语义主色和明确的文字变化。主题选项的选中边框与勾选标记使用当前主题的 `--primary`，不取预览缩略图颜色 |
| 操作 | 主要操作使用主色渐变与可读的 `--on-action`；次要操作用主色浅底；破坏性操作用 `--danger` |
| 深色 | 单独定义表面、边框、控件填充与按钮前景；不能直接对浅色主题做反相 |

普通正文与辅助说明按 WCAG AA 的 4.5:1 检查，较大文字和有意义的图标/控件边界按 3:1 检查；渐变按钮应检查渐变最不利位置。色彩不是唯一的状态信息。五主题均需在真实页面上复核，不用令牌表推断最终组合对比度。

## 暖陶 Milo 主题（默认）

新增第 4 个主题，id `milo`，名称「暖陶 Milo」，`theme-config.js` 中 `DEFAULT_THEME_ID = 'milo'`，原 3 个主题（露草蓝、星夜黑、星雾紫）原样保留，旧主题迁移映射不变。主题选择页自动读取主题目录，无需另加入口。

- 配色：暖奶油底 `#F7EDE3`、卡片米白 `#FAF9F7`、炭黑文字 `#2E2E2E`、辅助 `#6B6259`、蜜桃 `#F2A88A`、琥珀 `#E8A85C`、陶土 `#B7795A`，比例约 70/20/10；不使用绿色主色与高饱和粉蓝紫，不加森林自然元素。
- 对比度：蜜桃按钮配深色文字 `#3D2317`（7.4:1），不用白色文字（仅 1.95:1）；主色文字用深陶土 `#7A3E22`（7.16:1）；成功态改用琥珀 `#8A6317`，不用绿色。
- 质感：磨砂玻璃卡片与按钮、哑光陶瓷宠物、细颗粒背景（`--grain: 0.03`）、单一柔和暖灰阴影、右上暖光；阴影只用 `--shadow-card` / `--shadow-float` / `--shadow-btn` 各一种。

## 排版、几何与触控

- 系统中文无衬线为主体；Baloo 2 只用于数字。品牌 32px、页标题 23px、区块标题 19px、条目 17px、正文和表单 16px、说明与导航 14px。标题字重与说明文案拉开层级，中文正文不添加人为字距。
- 间距使用 4/8/12/16/24/32px；页面左右 20px，窄于 360px 为 16px；常规卡片内边距 18px，窄屏 16px；同级卡片间距 20px。列表内部间距用统一变量，不针对单张卡做位移补偿。
- 常规大卡片外圆角 40px，内嵌表面的角半径按“外半径 − 实际内缩 − 边框”计算；横纵内缩相同的角共享圆心。按钮、输入、分页、主题预览遵守各自的嵌套关系。支持时统一使用 `corner-shape: superellipse(1.25)`，不支持时以 `border-radius` 降级。
- 常规按钮、输入、分段项、筛选项、音频控件和图标按钮的点击框以 48px 为基准；整行开关通过包裹标签提供不低于 44px 的可触区域；底栏五个入口均有文本和图标。紧密分布的 10 级形态步进器另有可键盘操作的形态滑块，需在真机上核验触控等效性。
- 输入有可见标签、清楚的焦点、错误和禁用态；键盘焦点环不被卡片裁剪。回忆、伙伴、计划的分页与搜索不遮挡底栏。删除和无障碍标签写明对象；预览示例的本地隐藏操作明确写为“隐藏”，不使用永久删除文案。
- 低于 600px 时，承载标题、时间、进度与操作的培养计划卡改为单列；进度数值位于条外，使用高对比正文色，不叠在渐变填充上。小窝顶部进度轨道两端细、中间粗，整条仍维持 48px 点击区域。低于 360px 时，常用表现名称允许两行，记录日期与分值分行。图鉴卡可以保持两列，因为内容结构较轻。无备注的自动回忆只显示事件名称，不留空分隔符。

## 动效、性能与验收

按压反馈使用轻微缩放和颜色变化，选中态只做短暂反馈；持续视觉重心留给伙伴动作。`prefers-reduced-motion` 下停止非必要动效。普通卡片为实色表面，避免移动设备同时合成大量 `backdrop-filter` 层；宠物 3D 与合照编辑维持按需加载。

每次交付依次运行 `npm run typecheck`、`npm test`、`npm run build:web`、`npm run build:web:ios`，再核对两端产物。浏览器至少检查 320px、393px、430px、横屏、三主题、空内容和长文字；Android/iOS 真机分别检查安全区、系统返回、键盘、屏幕阅读器、最大系统字体、手势冲突和资源加载。浏览器通过不等于原生验收通过。
